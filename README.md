# Sufyan Ahmad: DevOps Portfolio

Live site: **https://sufyanahmadkamboh.github.io/**

Portfolio of a DevOps Engineer (AWS · Kubernetes · Terraform · CI/CD) based in Herborn, Germany. Plain HTML, CSS and JavaScript with no build step, works on mobile, has dark and light mode, and is hosted on GitHub Pages.

- `index.html`: the main page (about, experience, client projects, teaching-labs teaser, skills, contact)
- `labs.html`: the lab library, with a learning path, level and tool filters and search
- `lab.html?slug=<slug>`: one lab in full: overview, visual story player, skills, architecture and resources
- `projects.json`: the lab registry all three pages render from
- `assets/`: shared styles (`base.css`, `labs.css`) and the lab card code (`labs.js`)
- `projects/`: lab images, card covers (`<slug>-cover.webp`) and visual-story slides
- `Sufyan_Ahmad_CV_DevOps.pdf`: downloadable CV
