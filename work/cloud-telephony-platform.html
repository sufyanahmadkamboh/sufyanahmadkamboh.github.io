Employer projectLastingSales (HadiTelecom) · 2021 – 2024

Cloud PBX platform: millions of calls a month, kept running

I owned the production infrastructure of a cloud PBX and contact-center platform delivered with Zong (China Mobile Pakistan): the VoIP servers, the Kubernetes cluster for the customer portal, high availability, call-data lifecycle and security. I also automated server setup for the company's sales CRM.

Role: Senior VoIP & DevOps EngineerAsterisk · KamailioKubernetes · HAProxyJenkins · Ansible
🔒Confidential work. Customer names, hostnames, addresses and internal documents are left out on purpose. This page describes the engineering approach and what I did.
The context

Business phone systems for thousands of companies

The platform gives businesses a virtual phone system in the cloud: numbers, extensions, IVR menus, call queues, voicemail, call recording, surveys and a self-service portal, with reports for every call. It was delivered together with a national mobile operator and served 4,000+ business clients, processing 6M+ calls per month.

The same team also built LastingSales, a sales CRM for service businesses with lead capture, follow-ups, call recordings and a mobile app.

The challenges

What had to be solved

📞 Calls can't waitVoice is real-time: a server restart in the wrong place drops live calls for many companies at once.
🗃️ Call records pile upMillions of call records a month slowed down reports and the databases behind them.
🔄 Legacy deploymentsThe portal ran on hand-managed servers that were slow and risky to update.
🛡️ Carrier security standardsThe operator's security test had findings that had to be fixed on the public web apps.
⚙️ Manual server setupNew CRM servers took long to prepare and every one ended up slightly different.

What I did

My work, layer by layer

📞

VoIP platform operations

Kept the voice layer running for thousands of business tenants.

  • Ran the SIP proxy layer (Kamailio) in front of multiple Asterisk media servers, including Asterisk running in containers.
  • Owned multi-tenant dialplan changes: IVR, queues, time conditions, voicemail, caller-ID masking, call-back and feedback surveys, recording with automatic conversion to MP3.
  • Supervised the team developing custom SIP applications and dialplans for enterprise call routing.
  • Built concurrent-call graphs from call records to plan capacity.
AsteriskKamailioSIPDockerPython
☸️

Kubernetes and high availability for the portal

  • Moved the customer portal from hand-managed servers into containers on a high-availability MicroK8s cluster with MetalLB.
  • Put HAProxy in front for TLS termination, health checks and load balancing, with Keepalived holding a floating IP so a failed proxy is replaced automatically.
  • Built a private container registry with TLS for the platform's images.
  • Jenkins pipelines that build Docker images on every push to the development branch and deploy them, for zero-downtime releases.
Kubernetes (MicroK8s)MetalLBHAProxyKeepalivedJenkins
🗃️

Call-data lifecycle, storage and backups

  • Wrote archiving scripts that move call records older than 90 days to an archive database, day by day, with error handling, keeping reports fast.
  • Database backup and restore scripts; replicated MySQL and synced files between voice nodes.
  • Network storage with redundant disk pools and failover network links for recordings.
MySQLBashTrueNASlsyncd
🛡️

Network and security

  • Designed the network with separate VLANs for signalling, media and management on layer-3 switches, behind a firewall with VPN-only admin access.
  • Fixed findings from the operator's web-application security test: server upgrades, security headers (HSTS, CSP, frame protection), debug mode off and stricter upload limits.
  • Wrote the staff off-boarding and credential-rotation process.
  • Monitoring of hosts, services and calls, with centralised metrics and logs.

💼

Server automation for the LastingSales CRM

Automated how the CRM's servers are prepared and kept secure.

  • Ansible playbook that sets up a complete server for the web frontend, the backend and two microservices, with Apache and PM2.
  • Runbook and automation for wildcard TLS certificate renewal through DNS validation.
  • Servers on AWS and Azure, with Jenkins for builds and deployments.
